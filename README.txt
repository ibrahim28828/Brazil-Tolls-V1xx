Brazil Tool V1 — النسخة الكاملة

تتضمن هذه النسخة: صفحة تسجيل الدخول، فيديو الانترو فوق تسجيل الدخول، الخلفية واللوجو والتصميم الأصلي، وأقسام SKIN وWEAPON وEMOTE وAVATAR وBANNER، وروابط العناصر الموجودة، وقائمة القنوات الداعمة.

مهم: هذه نسخة ثابتة للعرض. العناصر الموجودة وروابطها مضمنة داخل index.html. لا توجد لوحة إدارة عامة لإضافة عناصر جديدة.

طريقة الرفع:
1) فك ضغط ملف ZIP.
2) ارفع مجلد brazil_tools_v1_site أو محتوياته إلى الاستضافة حسب طريقة الرفع التي يدعمها الموقع.
3) تأكد أن index.html داخل مجلد الموقع وأن مجلد assets موجود بجانبه، وفيه intro.mp4 والصور.
4) افتح رابط الموقع في نافذة خاصة واختبر تسجيل الدخول والأقسام وروابط التحميل.

ملاحظة: رفع هذه النسخة لا يغيّر الموقع المنشور تلقائياً؛ يجب استبدال ملفات الاستضافة بالملفات الموجودة هنا.
